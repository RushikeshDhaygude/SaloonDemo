Landing page for **Glow Beauty Studio** (Wakad, Pune).

## Live site

After GitHub Pages deploys:

**https://rushikeshdhaygude.github.io/SaloonDemo/**

Share that link with clients (works on mobile; no need to send HTML files).

## Local preview

```bash
cd /path/to/SaloonDemo
python3 -m http.server 8080
```

Open http://localhost:8080

## Files

- `index.html` — main page (GitHub Pages entry)
- `glow-beauty-studio.html` — same content (local editing)
- `images/glow/` — photos (required; keep folder next to HTML if sharing offline)
